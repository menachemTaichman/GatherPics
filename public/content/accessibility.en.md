**Accessibility Statement – Gather Pics**

Last Updated: January 2025

Gather Pics is committed to providing an accessible digital experience for all users, regardless of their abilities or disabilities. We strive to ensure that our Service is usable by everyone, including individuals who use assistive technologies.

This Accessibility Policy outlines our commitment, the accessibility features we provide, and how we work to meet accessibility standards.

---

We are committed to making Gather Pics accessible in accordance with:

We continuously work to improve accessibility and welcome feedback from users to help us identify and address accessibility barriers.

## 3. Keyboard Navigation

Gather Pics provides comprehensive keyboard navigation support:

### A. Basic Navigation
- **Tab Key**: Move forward through interactive elements (buttons, links, form fields)
- **Shift + Tab**: Move backward through interactive elements
- **Enter/Space**: Activate buttons and links
- **Escape (Esc)**: Close modals, dialogs, and menus

### B. Advanced Navigation
- **Arrow Keys**: Navigate through image galleries and grids
  - **Left/Right Arrows**: Move between images horizontally
  - **Up/Down Arrows**: Move between images vertically
  - Works in galleries, albums, moments, and group views
- **Ctrl/Cmd + A**: Select all images (where applicable)
- **Focus Management**: Focus is properly managed when opening and closing modals

### C. Focus Trapping
- Modals and dialogs trap focus within the active element
- Focus automatically returns to the triggering element when modals close
- Focus indicators are clearly visible on all interactive elements

## 4. Visual Accessibility

### A. Color Contrast
- Text and interface elements meet WCAG 2.1 Level AA contrast requirements
- Minimum contrast ratio of 4.5:1 for normal text
- Minimum contrast ratio of 3:1 for large text and UI components
- Focus indicators use high-contrast colors

### B. Focus Indicators
- **Clear Visual Indication**: All focusable elements have visible focus indicators
- **Focus Rings**: Prominent focus rings appear around focused elements
- **Consistent Styling**: Focus indicators are consistent throughout the Service

### C. Text and Typography
- Readable font sizes and line heights
- Text can be resized up to 200% without loss of functionality
- Clear typography hierarchy

### D. Responsive Design
- Service is responsive and works on various screen sizes
- Content adapts to different viewport sizes
- Mobile and tablet interfaces maintain accessibility features

## 5. Image Accessibility

### A. Alternative Text (Alt Text)

**Automatic Generation:**
- The system automatically generates basic alt text for all images
- Format: "Photo #[number] in [context]" (e.g., "Photo #5 in John's Album")
- Includes event name and photo index for context

**Manual Descriptions:**
- Photographers can add detailed manual descriptions to images
- Manual descriptions override automatic alt text when provided
- Descriptions are stored and displayed to assistive technologies

**Best Practices for Photographers:**
- We encourage adding meaningful descriptions, especially for important photos
- Descriptions should be concise but descriptive
- Consider the context and purpose of the image when writing descriptions

### B. Image Context
- Images are labeled with their context (album, moment, person, etc.)
- Photo indices help users understand image position in collections
- Face recognition groups are accessible with appropriate labels

### C. Decorative Images
- Decorative images are marked appropriately
- Functional images (buttons, icons) have descriptive alt text or ARIA labels
